Step 1

Outlook — Windows (recommended: .htm file)

  1. Click Download .htm (Outlook desktop).
  2. Open File Explorer and paste this into the address bar: %APPDATA%\Microsoft\Signatures
  3. Copy the downloaded Jane-Doe.htm into that folder.
  4. Open Outlook → File → Options → Mail → Signatures.
  5. Pick the signature under New messages and Replies/forwards → OK.

Outlook — Windows / Mac / Web (paste)

  1. Click Click here to copy.
  2. Outlook Web / new Outlook: Settings (gear) → Mail → Compose and reply → Email signature.
    Outlook Mac: Outlook → Settings → Signatures → +.
    Outlook Windows: File → Options → Mail → Signatures → New.
  3. Paste with Ctrl + V (Windows) or Cmd + V (Mac). Do not use "paste as plain text".
  4. Assign the signature to New messages and Replies/forwards, then save.

Adding people

All the data lives in employees.csv, one row per person. Fill it in and run node signature-generator.js to rebuild every page.

  • position — the yellow pill. Leave it empty and the pill is not rendered at all.
  • nameImage — optional artwork for the name (193x34). Leave it empty and the name is written as live text, which always follows the palette below.
  • officeAddress — optional per-person address, lines separated by |, field wrapped in quotes.

Dark mode

Handled the way the African signatures handle it: the signature paints no background of its own, so it sits on whatever the client gives it, and every colour is a mid-tone that clears roughly 4:1 against white and against near-black. Media queries are not an option here — signature forms keep the inline styles and drop the <style> block.

  • Text #8C6E80 · surname and links #A05FB8 · rule #927373.
  • The yellow pill and the round icons are filled shapes: they carry their own contrast, so they hold up either way.
  • Artwork has to follow the same rule, because no client recolours an image. Anything near-black on transparency — the maroon in the name artwork, the "INTERNATIONAL" wordmark in the lockup — disappears on a dark background, so those two files need a re-export in #8C6E80 / #A05FB8. Until then, clearing nameImage in the CSV renders the name as text and is correct in both modes.

Known client limitations

  • Outlook desktop for Windows uses the Word engine: it ignores transform, so the job-title pill sits straight instead of tilted.
  • The stacked mobile layout relies on a media query. Outlook for iOS/Android, Apple Mail and the Gmail app honour it when it survives the paste; Outlook desktop keeps the 594px two-column layout, which is the intended behaviour.
