Install

Outlook — Windows (recommended: .htm file)

  1. Click Download .htm (Outlook desktop).
  2. Open File Explorer and paste this into the address bar: %APPDATA%\Microsoft\Signatures
  3. Copy the downloaded SleepOver-Matoks-PM.htm into that folder.
  4. Open Outlook → File → Options → Mail → Signatures.
  5. Pick the signature under New messages and Replies/forwards → OK.

Outlook — Windows / Mac / Web (paste)

  1. Click Click here to copy.
  2. Outlook Web / new Outlook: Settings (gear) → Mail → Compose and reply → Email signature.
    Outlook Mac: Outlook → Settings → Signatures → +.
    Outlook Windows: File → Options → Mail → Signatures → New.
  3. Paste with Ctrl + V (Windows) or Cmd + V (Mac). Do not use "paste as plain text".
  4. Assign the signature to New messages and Replies/forwards, then save.
