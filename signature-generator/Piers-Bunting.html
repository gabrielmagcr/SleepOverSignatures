Step 1

Outlook — Windows (recommended: .htm file)

  1. Click Download .htm (Outlook desktop).
  2. Open File Explorer and paste this into the address bar: %APPDATA%\Microsoft\Signatures
  3. Copy the downloaded Piers-Bunting.htm into that folder.
  4. Open Outlook → File → Options → Mail → Signatures.
  5. Pick the signature under New messages and Replies/forwards → OK.

Outlook — Windows / Mac / Web (paste)

  1. Click Click here to copy.
  2. Outlook Web / new Outlook: Settings (gear) → Mail → Compose and reply → Email signature.
    Outlook Mac: Outlook → Settings → Signatures → +.
    Outlook Windows: File → Options → Mail → Signatures → New.
  3. Paste with Ctrl + V (Windows) or Cmd + V (Mac). Do not use "paste as plain text".
  4. Assign the signature to New messages and Replies/forwards, then save.

Adding people

All the data lives in employees.csv, one row per person. Fill it in and run node signature-generator.js to rebuild every page.

  • position — the job title, printed in capitals under the name. Leave it empty and the line is not rendered at all.
  • nameImage — optional artwork for the name, exported at 392x116 and placed at 196x58. The current export also contains the job-title sticker, so when it is set the position line is not typeset on top of it. Leave it empty and the name is live text plus a typeset title.
  • officeAddress — optional per-person address, lines separated by |, field wrapped in quotes.

Dark mode

The signature paints no background of its own, so it sits on whatever the client gives it. Media queries are not an option here — signature forms keep the inline styles and drop the <style> block — so everything rests on the colours themselves.

  • All type and the divider are pure black #000000. Gmail and Outlook dark mode run a lightness inversion over any message that looks light to them, and pure black is the value that comes back as near-white. A mid-tone only gets nudged, so it ends up muddy — black in, white out.
  • The artwork is never inverted by any client, so the yellow lockup, the yellow-and-purple name and the round icons carry their own fill and read either way.
  • The dark preview above is the worst case: a client that darkens the card but skips the inversion. Gmail and Outlook both invert, so what they show is the light preview with the type flipped to white. Worth checking on a phone before rollout.

Known client limitations

  • Only the email address and the website are links. Both phone numbers are plain text on purpose, so no client turns them into a tel: handler.
  • The stacked mobile layout relies on a media query. Outlook for iOS/Android, Apple Mail and the Gmail app honour it when it survives the paste; Outlook desktop keeps the 594px two-column layout, which is the intended behaviour.
